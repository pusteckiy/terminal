# KuCoin, Kraken, Pacifica market data

Checked against official documentation and public REST/WebSocket responses on 2026-10-03. These are price-aggregated books, not individual orders.

## KuCoin

- Preferred public book transport: `wss://x-push-spot.kucoin.com` and `wss://x-push-futures.kucoin.com` require no token. Wait for `{message:"welcome",pingInterval:18000}`; then send `{id:"1",action:"subscribe",channel:"obu",tradeType:"SPOT"|"FUTURES",symbol:"BTC-USDT"|"XBTUSDTM",depth:"increment@10ms",rpiFilter:0}`. **Lowercase `subscribe` is necessary in live probes**; uppercase was acknowledged but produced no data. Both live endpoints sent initial 500 levels/side, then consecutive deltas. Received frames are binary UTF-8 JSON, not compressed. Ping `{id,op:"ping"}` returns `{op:"pong",id,ts}`. [Lifecycle](https://www.kucoin.com/docs-new/websocket-api/introduction), [500-level book](https://www.kucoin.com/docs-new/3470354w0).
- UTA book envelope `{T:"obu.SPOT"|"obu.FUTURES",dp:"increment@10ms",t:"snapshot"|"delta",P:<ns>,d:{s,O,C,M:<ns>,b:[[price,size]],a:[[price,size]]}}`: replace on snapshot; on delta require `O <= lastC+1` and `C > lastC`, quantities absolute and zero deletes, then advance lastC. This stream initializes without REST and sends zero when a level leaves the top 500. Depth 500 is the supported window, not the complete exchange book. Old UTA `increment` is documented as deprecated since 2026-07-15. [Book lifecycle and pruning](https://www.kucoin.com/docs-new/3470354w0).
- UTA trade subscription `{id:"2",action:"subscribe",channel:"trade",tradeType:"SPOT"|"FUTURES",symbol:...}` shares the book socket. Trade envelope `{T:"trade.SPOT"|"trade.FUTURES",P:<ns>,d:{p,q,s,S:"buy"|"sell",E,ti,M:<ns>}}` verified live for spot BTC/ETH and futures BTC/SOL. Convert futures q from contracts; keep all individual messages. [UTA trades](https://www.kucoin.com/docs-new/3470359w0).
- Spot catalog: `GET https://api.kucoin.com/api/v2/symbols`; use `symbol`, `baseCurrency`, `quoteCurrency`, filter `enableTrading`. Linear perpetual catalog: `GET https://api-futures.kucoin.com/api/v1/contracts/active`; filter `status=Open`, `isInverse=false`, no `expireDate`. Convert futures contract quantity to base with `multiplier` (live `XBTUSDTM`: `0.001`). [Spot catalog](https://www.kucoin.com/docs-new/rest/spot-trading/market-data/get-all-symbols), [contracts](https://www.kucoin.com/docs-new/rest/futures-trading/market-data/get-all-symbols).
- POST `/api/v1/bullet-public` on the matching REST host. Read token and `instanceServers[0]`; append `?token=<encoded>&connectId=<unique>` to its endpoint. Live endpoints: `wss://ws-api-spot.kucoin.com/`, `wss://ws-api-futures.kucoin.com/`. Wait for `type=welcome`, then subscribe with `{id,type:"subscribe",topic,response:true}`. Send `{id,type:"ping"}` according to returned `pingInterval` (live 18000ms), monitor `pong` using `pingTimeout` (10000ms); connections expire after 24h. [Spot token](https://www.kucoin.com/docs-new/websocket-api/base-info/get-public-token-spot-margin), [futures token](https://www.kucoin.com/docs-new/websocket-api/base-info/get-public-token-futures), [lifecycle](https://www.kucoin.com/docs-new/websocket-api/base-info/introduction).
- Public spot book snapshots: **`/spotMarket/level2Depth50:{symbol}`**, 50 levels/side at 100ms, `data.asks/bids` are `[price,size]` strings; replace both sides. `/market/level2Depth50` is invalid (live 404). Public partial REST `/api/v1/market/orderbook/level2_100` provides 100 levels. Full spot REST `/api/v3/market/orderbook/level2` requires General API permission; do not claim an unauthenticated full book. [WS 50](https://www.kucoin.com/docs-new/3470070w0), [partial REST](https://www.kucoin.com/docs-new/rest/spot-trading/market-data/get-part-orderbook), [full REST permissions](https://www.kucoin.com/docs-new/rest/spot-trading/market-data/get-full-orderbook).
- For a synchronized spot incremental book, buffer `/market/level2:{symbol}` before snapshot. Require `sequenceStart <= previousEnd+1` and `sequenceEnd > previousEnd`; discard old per-level sequences; quantity zero deletes. [Spot incremental algorithm](https://www.kucoin.com/docs-new/3470068w0).
- Full futures snapshot `/api/v1/level2/snapshot?symbol=...` is public. Buffer `/contractMarket/level2:{symbol}`, then replay consecutive `data.sequence`; `data.change` is `price,buy|sell,quantity`. Quantity is absolute, zero deletes; resnapshot on gaps. Snapshot `ts` is nanoseconds; delta `timestamp` is milliseconds. [Snapshot](https://www.kucoin.com/docs-new/rest/futures-trading/market-data/get-full-orderbook), [futures incremental](https://www.kucoin.com/docs-new/3470082w0).
- Every trade: `/market/match:{symbol}` for spot; `/contractMarket/execution:{symbol}` for futures. `data` contains price, size, side, tradeId; spot `time` and futures `ts` are nanoseconds. Buy/sell reflects taker direction; multiply futures size by multiplier. [Spot trades](https://www.kucoin.com/docs-new/3470072w0), [futures trades](https://www.kucoin.com/docs-new/3470084w0).
- Spot candle REST `/api/v1/market/candles?symbol=...&type=1min&startAt=<sec>&endAt=<sec>` returns `[startSec,open,close,high,low,baseVolume,quoteTurnover]`, newest first, maximum 1500. Futures `/api/v1/kline/query?symbol=...&granularity=1&from=<ms>&to=<ms>` returns `[startMs,open,high,low,close,contracts,quoteTurnover]`, maximum 500. Live granularity 1 means one minute. Sort ascending and multiply futures volume by multiplier. [Spot candles](https://www.kucoin.com/docs-new/rest/spot-trading/market-data/get-klines), [futures candles](https://www.kucoin.com/docs-new/rest/futures-trading/market-data/get-klines).
- WS candle topics: `/market/candles:{symbol}_1min`, `/contractMarket/limitCandle:{symbol}_1min`; both use `[startSec,open,close,high,low,volume,...]`. Futures candle volume is explicitly documented as incorrect; prefer trade-derived live candle updates. [Spot WS candles](https://www.kucoin.com/docs-new/3470071w0), [futures WS warning](https://www.kucoin.com/docs-new/3470086w0).

## Kraken

- Spot catalog `GET https://api.kraken.com/0/public/AssetPairs?assetVersion=1`: keys are canonical v2 symbols (`BTC/USD`), base/quote are display names. `wsname` remains legacy `XBT/USD`, so do not use it for v2. Live REST OHLC accepts `pair=BTC/USD` directly. Filter online crypto currency pairs. [AssetPairs](https://docs.kraken.com/api-reference/market-data/get-tradable-asset-pairs), [v2 instrument reference](https://docs.kraken.com/exchange/api-reference/spot-websocket-v2/instrument).
- Public spot WS `wss://ws.kraken.com/v2`: `{method:"subscribe",params:{channel:"book",symbol:["BTC/USD"],depth:1000,snapshot:true}}`. Book messages have `type=snapshot|update`, `data:[{symbol,bids:[{price,qty}],asks:[{price,qty}],checksum,...}]`. Depth options 10/25/100/500/1000. Apply all changes in received order, zero qty deletes, then **truncate to subscribed depth after every message**: levels leaving scope receive no zero deletion. [Book](https://docs.kraken.com/exchange/api-reference/spot-websocket-v2/book), [maintenance guide](https://docs.kraken.com/exchange/guides/websockets/book-checksum-v2).
- Optional CRC32 checks top 10 asks ascending, then top 10 bids descending; concatenate each price and qty after removing decimal points and leading zeroes. Preserve raw numeric trailing zeroes (live qty `0.01000000` and price `84584.0`), not f64 stringification. Published fixture checksum: `3310070434`. Reconnect/resnapshot on mismatch. [Checksum guide](https://docs.kraken.com/exchange/guides/websockets/book-checksum-v2).
- Spot trade subscription: channel `trade`, symbol array, `snapshot:false`. Each `data[]` trade has taker `side`, price, qty in base, trade_id, RFC3339 timestamp. Handle every array entry. [Trades](https://docs.kraken.com/exchange/api-reference/spot-websocket-v2/trade).
- Spot OHLC REST `/0/public/OHLC?pair=BTC%2FUSD&interval=1` returns up to 720 rows `[timeSec,open,high,low,close,vwap,baseVolume,count]`; last row is current candle. WS channel `ohlc`, interval 1, supplies `{open,high,low,close,volume,interval_begin}`; parse `interval_begin`, not deprecated timestamp (which is interval end in live responses). [REST OHLC](https://docs.kraken.com/api-reference/market-data/get-ohlc-data), [live OHLC](https://docs.kraken.com/exchange/api-reference/spot-websocket-v2/ohlc).
- Perpetual catalog `GET https://futures.kraken.com/derivatives/api/v3/instruments`: choose `PF_` symbols with `tradeable=true` and `isExpired=false`; type is `flexible_futures`, base/quote supplied. PF linear quantities are in base, with no contract multiplier; live `PF_XBTUSD` book sizes include `0.5789` BTC. [Instruments](https://docs.kraken.com/api-reference/instrument-details/get-instruments), [linear specifications](https://support.mtf.kraken.com/hc/en-us/articles/25499987607837-Linear-Contract-Specifications).
- Public futures WS `wss://futures.kraken.com/ws/v1`: `{event:"subscribe",feed:"book"|"trade",product_ids:["PF_XBTUSD"]}`. `book_snapshot` supplies bids/asks `{price,qty}`, seq and timestamp ms; subsequent `book` supplies side buy/sell, price, absolute qty, seq, timestamp. Check consecutive seq, resnapshot on gap. `trade_snapshot.trades` arrives newest first; live `trade` supplies uid, taker side, qty base, price and time ms. [Book](https://docs.kraken.com/api/docs/futures-api/websocket/book/), [trades](https://docs.kraken.com/exchange/api-reference/futures-websocket/trade).
- Futures trade candle history `https://futures.kraken.com/api/charts/v1/trade/PF_XBTUSD/1m?from=<seconds>&to=<seconds>` returns `candles:[{time:<ms>,open,high,low,close,volume}]` plus `more_candles`; live checked, volume is base. No native futures candle WS channel listed; maintain active candle from trades. [Charts](https://docs.kraken.com/api/docs/futures-api/charts/candles).

## Pacifica

- **Spot is now live**, not perpetual-only. Catalog `GET https://api.pacifica.fi/api/v1/info` contains `instrument_type` (`perpetual` or `spot`), `symbol`, `base_asset`, tick_size and market lot_size. Live spot `SOL-USDC` is distinct from perp `SOL`; spot quotes USDC. Preserve exact case, including lowercase prefix in `kPEPE`. `/spot_assets` lists collateral assets, not trading pairs, and has a different asset lot size; use `/info` for markets. [Market catalog](https://docs.pacifica.fi/api-documentation/api/rest-api/markets/get-market-info), [spot trading](https://docs.pacifica.fi/trading-on-pacifica/spot-trading), [symbol case](https://docs.pacifica.fi/api-documentation/api/market-symbols), [assets](https://docs.pacifica.fi/api-documentation/api/rest-api/spot/get-spot-assets).
- Public WS `wss://ws.pacifica.fi/ws`; subscriptions `{method:"subscribe",params:{source:...,symbol:"SOL-USDC",...}}` work identically for spot and perp. Send `{method:"ping"}` before 60 seconds of outbound inactivity; reconnect at 24h. [WS lifecycle](https://docs.pacifica.fi/api-documentation/api/websocket).
- Source `book`, `agg_level:1` (choices 1/10/100/1000/10000): complete `data.l=[bids,asks]`, each `{p:<price string>,a:<base amount string>,n:<order count>}`, s symbol, t ms, li symbol event sequence. Replace both sides; cadence 250ms. REST `/api/v1/book?symbol=...&agg_level=1` is limited to 10 levels/side; no full book guarantee in docs. [WS book](https://docs.pacifica.fi/api-documentation/api/websocket/subscriptions/orderbook), [REST depth limit](https://docs.pacifica.fi/api-documentation/api/rest-api/markets/get-orderbook).
- Source `bbo` gives event-driven best quote updates: `data={s,i,li,t,b,B,a,A}`; lowercase b/a prices, uppercase B/A base sizes. Prefer this for PRICES quote lines over 250ms book snapshots. [BBO](https://docs.pacifica.fi/api-documentation/api/websocket/subscriptions/best-bid-offer-bbo).
- Source `trades` provides every `data[]` item `{h,s,a,p,d,tc,t,li,it}`: h history id; a base amount; t ms. Map open_long/close_short to buy, open_short/close_long to sell. **Live spot SOL-USDC trades still have it=0**, so product kind must come from catalog and exact symbol. [Trades](https://docs.pacifica.fi/api-documentation/api/websocket/subscriptions/trades).
- Candle REST `/api/v1/kline?symbol=...&interval=1m&start_time=<ms>&end_time=<ms>&limit=...`, capped at 4000. Source `candle`, interval `1m`; history and live payloads use `{t,T,s,i,o,c,h,l,v,n}`, t/T ms and v base. Spot SOL-USDC book, BBO, trades and candle subscriptions all verified live without extra instrument parameters. [History](https://docs.pacifica.fi/api-documentation/api/rest-api/markets/get-candle-data), [WS candles](https://docs.pacifica.fi/api-documentation/api/websocket/subscriptions/candle).

## Integration safeguards

Reinitialize state on reconnect. Route by exchange, market kind and exact symbol. Do not mix trade sequences with book sequences. Never combine a partial snapshot with arbitrary deeper updates and advertise it as a full book. Reject crossed or malformed books; sequence gaps/checksum mismatches should trigger recovery. Maintain live candles from trades where native candle data is absent or unreliable.

Kraken Spot book prices and quantities are decoded as raw JSON values to preserve numeric trailing zeroes for CRC validation. Keep this handling at the exchange boundary: global `serde_json/arbitrary_precision` breaks floating-point candle fields in the terminal's internally tagged WebSocket messages (`invalid type: map, expected f64`). A protocol regression test covers both history snapshots and live candles.
